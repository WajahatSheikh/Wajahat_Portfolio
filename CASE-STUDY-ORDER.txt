Yeh aap ki 10 case studies hain, abhi jis order mein site par hain.

KAISE USE KAREIN:
  1. Blocks ko upar-neeche move kar ke apna order bana lein.
  2. Numbers theek karne ki zaroorat NAHI - main order lines se parh lunga.
  3. File save karein aur mujhe bata dein.

  Koi project hatana ho to us ka poora block delete kar dein.
  Title ya subtitle badalna ho to yahin edit kar dein, main utha lunga.
